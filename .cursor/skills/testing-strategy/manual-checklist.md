# 手動確認チェックリスト（自動化対象外）

Push / PWA / iOS は自動化しない。リリース前や関連変更時に手動で確認する。

## Web Push

- [ ] 通知許可ダイアログから購読できる
- [ ] 他メンバーの投稿で Push が届く（購読端末）
- [ ] 購読解除後に届かない
- [ ] 失効エンドポイント（410/404）時に購読レコードが消える想定どおりか（ログ/DB）

## PWA

- [ ] manifest / アイコンが正しい
- [ ] Service Worker が登録され、再訪でキャッシュが効く（オフラインはベストエフォート）
- [ ] ホーム画面追加（対応ブラウザ）
- [ ] 更新前のインストール済みPWAが、初回移行時に新しいアプリシェルへ再読み込みされる（未保存フォームは消える前提）
- [ ] クライアントのみの更新でも更新依頼が表示され、「更新して再読み込み」で新しい画面になる
- [ ] API互換性を壊す更新では、旧クライアントのAPI呼び出しが426で拒否され、更新後に復帰する
- [ ] 2タブで開いた状態でも、片方の更新後にもう片方が旧APIを実行しない
- [ ] 更新後の再読み込みでもログイン状態とPush購読が維持される

## iOS

- [ ] Safari 非 standalone でホーム画面追加案内が出る
- [ ] ホーム画面追加後（standalone）で Push 購読できる
- [ ] 実機で投稿通知を受信できる

## 認証まわり（補足）

- [ ] 本番 HTTPS で `session` Cookie に `Secure` が付く
- [ ] ローカル HTTP でもログイン Cookie が保存される
